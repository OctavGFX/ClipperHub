YouTube Shorts
How to set it up (10 minutes, once)
  1. Open console.cloud.google.com, create a project (any name).
  2. APIs & Services > Library: enable YouTube Data API v3.
  3. OAuth consent screen (Google Auth Platform): External, app name "ClipperHub", your email. Under Audience press Publish app (in "Testing" Google signs you out every 7 days).
  4. Clients > Create client > type Desktop app. Copy the Client ID and Client secret here, Save, then Connect.
  5. Google will warn "app isn't verified": it is your own app, choose Advanced > continue.
Instagram Reels
How to set it up (10 minutes, once)
  1. Your Instagram must be a Creator or Business account (Instagram app: Settings > Account type).
  2. Open developers.facebook.com, create an app (type Business, use case "Manage messaging & content on Instagram").
  3. In the app: Instagram > API setup with Instagram login > Add account (your Instagram), then Generate token.
  4. Paste the token here, Save, then Check. If the token expires or is revoked, reconnect.
  5. Each Reel is shared through a temporary private link (cloudflared) for the minute Instagram needs to fetch it.
Telegram bot
How to set it up (2 minutes, once)
  1. In Telegram, open @BotFather, send /newbot, pick any name.
  2. Copy the token it gives you here and Save.
  3. Open your bot in a private Telegram chat and press Start. With delivery set to Review in ClipperHub, click Connect & test here to link the chat.
  4. Then you can choose Review in Telegram for video imports and YouTube approval. Telegram also lets you copy the TikTok caption and post it yourself.
